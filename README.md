# Adaptive Emergency Evacuation Route Optimization

An intelligent emergency response navigation system built in C++ that dynamically calculates safe evacuation routes during disasters (floods, fires, road blockages) using graph theory and shortest-path algorithms.

---

## 📌 Project Overview

During severe emergencies, standard GPS routes can become hazardous or impassable due to sudden road damage, active hazard zones, or traffic jams. Traditional static routing algorithm systems fail to adapt in real time. 

This project models a city road network as a **dynamic weighted graph**. It computes optimal routes to safety centers using **Dijkstra's Algorithm combined with a Priority Queue**. When road conditions change, the edge weights update dynamically to recalculate safe alternate paths, bypassing affected zones.

================================================================================
                    SYSTEM ARCHITECTURE EXECUTION PIPELINE                      
================================================================================

 [1] USER INPUT
     │  * Receives Origin Node (Start Location)
     │  * Receives Destination Node (Evacuation Center / Safe Zone)
     ▼
 [2] ROAD NETWORK DATA
     │  * Map converted to Graph Nodes (Location objects)
     │  * Edges assigned dynamic weights (Road objects with travel time)
     ▼
 [3] DIJKSTRA'S ALGORITHM + PRIORITY QUEUE
     │  * Evaluates shortest path using Min-Heap
     │  * Calculates optimal evacuation route based on current weights
     ▼
 [4] INITIAL BEST ROUTE
     │  * Primary evacuation route established and displayed to user
     ▼
 [5] ROAD CONDITION UPDATE (DYNAMIC TRIGGER)
     │  * Incident detected (e.g., road blockage, flooding, heavy risk)
     │  * Affected Road status changed to Blocked / Hazard level scaled
     ▼
 [6] ALTERNATE ROUTE RE-CALCULATION
     │  * Dynamic route optimization triggered
     │  * New safe path generated bypassing affected edges
     
================================================================================

## ⚙️ Key Features

* **Dynamic Edge Weighting:** Calculates dynamic cost based on base travel time, risk/hazard multipliers, and total road closure flags[cite: 1].
* **Safety Center Routing:** Prioritizes routing affected citizens toward designated evacuation zones and medical centers[cite: 1].
* **Real-time Re-routing:** Reroutes traffic away from blocked or risky edges dynamically without rebuilding the entire graph[cite: 1].
* **Object-Oriented Design:** Built using clean, modular OOP architecture in C++[cite: 1].

---

## 🛠️ Data Structures & Algorithms Used

* **Graph Representation:** Adjacency List for space-efficient storage of nodes and edges[cite: 1].
* **Priority Queue / Min-Heap:** Fast node extraction with $O(\log V)$ efficiency during shortest path lookup[cite: 1].
* **Dijkstra’s Algorithm:** Evaluates total path costs dynamically to compute safe evacuation routes[cite: 1].
* **Object-Oriented Programming (OOP):** Core entities structured via encapsulation (`Location`, `Road`, `Graph`, `RouteOptimizer`)[cite: 1].
